# What keyboard shortcuts are available?

Use `Cmd` on macOS and `Ctrl` on Windows/Linux. Shortcuts are ignored while typing in an input or text area.

| Shortcut | Action |
| --- | --- |
| `Space` | Play / pause |
| `Cmd/Ctrl + →` | Next track |
| `Cmd/Ctrl + Alt + →` | Fast forward |
| `Cmd/Ctrl + ←` | Previous track |
| `Cmd/Ctrl + Alt + ←` | Rewind |
| `Cmd/Ctrl + ↑` | Volume up |
| `Cmd/Ctrl + ↓` | Volume down |
| `Cmd/Ctrl + Alt + ↓` | Mute toggle |
| `Cmd/Ctrl + S` | Shuffle toggle |
| `Cmd/Ctrl + R` | Cycle repeat mode |
| `Cmd/Ctrl + F` | Go to search |
| `Ctrl + Cmd + F` (macOS), `Ctrl + Alt + F` (Windows) | Toggle fullscreen |
